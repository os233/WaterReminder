使用文档

从第一次打开到提醒稳定运行，下面这些是实际会用到的部分。

首次启动

  • Android 13+ 会弹出通知权限申请，允许后提醒才能显示
  • Android 12+ 需要在系统设置里授予「闹钟和提醒」权限，否则提醒时间会不准
  • 部分国产 ROM（小米 / 华为 / OPPO / vivo 等）需要手动允许自启动与后台运行，否则提醒会被系统清理掉
  • 建议关闭针对本应用的电池优化，长期挂后台才稳

日常使用

  • 记录：首页点饮品按钮记一杯；需要精确的毫升数就用「自定义」输入
  • 目标：点首页的目标数字即可修改，范围 1000–4000 ml，步长 100
  • 提醒：首页进入「设置提醒」，选 1 / 2 / 3 小时间隔；夜间免打扰可设起止时间，支持跨午夜
  • 历史：首页进入历史页，查看最近 7 天汇总与月历；长按删除单条记录，或点右上角删除按钮清空当日记录

关于水合系数

不同饮品的实际补水效果不同，所以总量不是简单把毫升数相加，而是乘上系数后再累计。

饮品系数说明
水1.00白水
茶0.95
果汁0.85
咖啡0.80
气泡水1.00

例如 200 ml 咖啡按 160 ml 计入当日总量。

更新

App 启动时会读取本站（GitHub Pages）上的静态版本清单，发现更高的版本号就弹窗提示，确认后下载安装包、校验 SHA-256，再交给系统安装。

  • 版本比较用的是整数 versionCode，不解析版本号字符串，所以「1.10.0 比 1.9.0 新」这类判断是可靠的
  • 为避免频繁请求，自动检查最多每 12 小时一次
  • 想立刻检查：首页滑到底部点「关于」→「检查更新」。手动检查不受 12 小时限制，并会区分「已是最新」和「没查到」
  • 检查更新失败（断网、版本清单取不到等）不会影响 App 正常使用，只是不提示
  • 预发布（beta）版本不会推送给 App —— 它不写进版本清单，只能到 GitHub Releases 手动下载
  • 安装包必须由本项目发布密钥签名，签名不一致时系统会拒绝覆盖安装

常见问题

提醒不响或不准时

  1. 确认已授予通知权限与「闹钟和提醒」权限
  2. 在系统设置里把本应用加入电池优化白名单，并允许自启动 / 后台运行
  3. 检查免打扰时段是否覆盖了当前时间（支持跨午夜，容易设反）

换了手机，记录会同步过来吗

不会。饮水记录只存在本机数据库里，App 不上传也不下载任何用户数据，请用系统自带的备份 / 换机工具迁移。

想装旧版本

到 GitHub Releases 选对应版本即可。注意：不同签名的包无法互相覆盖安装。

发现 bug 或想提需求

欢迎到 GitHub Issues 反馈，附上机型、Android 版本与复现步骤会快很多。
