隐私政策

生效日期：2026-09-15 · 适用应用：喝水提醒 WaterReminder（com.example.waterreminder）

一句话版本：这个应用不收集、不上传你的任何个人数据，饮水记录只存在你自己的手机上。

1. 收集哪些数据

不收集。应用不要求注册账号，不索取姓名、手机号、邮箱、位置、通讯录、相册等任何个人信息。

2. 是否上传用户数据

不上传。应用没有账号体系，也没有自建的服务端，你的饮水记录、目标设置、提醒设置都不会离开设备。

3. 饮水记录保存在哪里

保存在设备本地的应用私有数据库（Android Room / SQLite）与本地偏好设置中。卸载应用或在系统设置里清除应用数据，这些记录会被一并删除。

4. 是否使用第三方服务

应用不集成任何第三方 SDK，不含广告 SDK、崩溃上报 SDK、推送 SDK 或统计分析 SDK。

5. 网络请求说明

应用唯一的网络行为是检查版本更新：启动时向 GitHub 的公开 API 请求最新发布版本（https://api.github.com/repos/os233/WaterReminder/releases/latest），有新版本时从 GitHub Releases 下载安装包。

  • 该请求只读取公开的版本信息，不携带任何用户数据
  • 与任何网络请求一样，GitHub 作为服务方会看到发起请求的 IP 地址与 User-Agent，这属于其自身的隐私政策管辖范围
  • 请求失败或断网时应用会静默跳过检查，不影响正常使用
  • 为避免频繁请求，自动检查最多每 12 小时一次

6. 是否包含统计服务

不包含。应用不上报使用行为、不记录页面停留、不做用户画像。

7. 应用权限说明

权限用途
通知显示喝水提醒
闹钟和提醒按设定间隔精确触发提醒
开机自启重启后恢复提醒计划
前台服务常驻轻量通知，避免提醒被系统清理
网络仅用于检查更新与下载安装包
安装未知应用安装下载好的新版本安装包

这些权限都只服务于本机功能，不用于采集数据。

8. 如何删除数据

  • 删除单条记录：在应用的「历史」页长按 / 多选后删除
  • 删除全部数据：系统设置 → 应用 → 喝水提醒 → 存储 → 清除数据；或直接卸载应用

数据只在本机，删除后无法恢复，也没有服务端副本。

9. 儿童隐私

应用不面向儿童设计，也不会有意收集儿童的任何信息 —— 实际上它不收集任何人的信息。

10. 政策变更

本政策如有修改，会更新本页顶部的生效日期，并通过版本发布记录说明。继续使用更新后的版本即视为接受修改后的政策。

11. 联系方式

对本政策有疑问，可以在 GitHub Issues 提出， 或查看项目主页 github.com/os233/WaterReminder。
