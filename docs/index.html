喝水提醒 WaterReminder

按小时提醒你喝水，记录每一杯，并按饮品类型折算真实补水量。开源、无广告、无账号、不上传任何数据。

功能

一键记录

5 种饮品类型（水 / 茶 / 果汁 / 咖啡 / 气泡水），也可直接输入任意毫升数。

按水合系数折算

不同饮品的补水效果不一样，按系数计入当日总量，而不是简单累加毫升数。

目标与进度

每日目标 1000–4000 ml 可调，首页环形进度显示完成百分比，并统计连续达标天数。

可靠提醒

1 / 2 / 3 小时间隔循环提醒；免打扰时段支持跨午夜（如 22:00 – 次日 08:00）；开机自动恢复。

历史与统计

最近 7 天汇总、月历视图按日查看，支持多选删除。

数据只在本机

饮水记录存在设备本地数据库，不联网上传；App 唯一的网络请求是检查有没有新版本。

水合系数

例如 200 ml 咖啡按 160 ml 计入当日总量。
