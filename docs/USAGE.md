# 功能与使用说明

喝水提醒 WaterReminder 的完整功能清单与使用说明。仓库主页见 [README](../README.md)。

## 记录

- 首页点饮品卡片记一杯，或通过「自定义」输入任意毫升数（1 – 5000，范围外红框提示而不是默默丢弃）
- 记录入口不止首页：**提醒通知与桌面小部件上都有 +200 / +350 / +500 ml 快捷记录按钮**，点一下就记上
- 记录后底部弹出「已记录 · 撤销」提示，误触不用去历史页找
- **水合系数折算**：不同饮品按实际补水效果计入总量，而不是简单累加毫升数

| 饮品 | 系数 | 说明 |
| --- | --- | --- |
| 水 | 1.00 | 白水 |
| 茶 | 0.95 | |
| 咖啡 | 0.80 | |
| 果汁 | 0.85 | |
| 气泡水 | 1.00 | |

  例如 200ml 咖啡按 160ml 计入当日总量

## 目标与统计

- **首启引导**：首次使用按性别 / 体重 / 运动量计算推荐每日目标（EFSA 总水分口径，可手改），顺带配好提醒；之后可从「关于」重新运行
- 首页**水球波浪进度**：水位随饮水量上升，水面持续流动；总数带滚动动画
- 每日目标可设 1000 – 5000 ml（步长 100，默认 2000），点首页目标数字即可修改
- 连续达标天数（streak）统计
- 历史页三合一统计卡：日期切换、最近 7 天柱状图（含目标参考线、日均）、**本月达标 x/y 天 · 连续 x 天**、月历视图（达标/有记录/选中三态，上滑收起）
- 记录列表扁平化展示，左滑或长按删除单条（可撤销），或一键清空当日记录
- **CSV 导出**：历史页一键把全部记录导出为 CSV（系统文件选择器选位置，零存储权限）

## 提醒

- 按 1 / 2 / 3 小时间隔循环提醒，通知带提示音与震动
- 提醒通知自带 **+200 / +350 / +500 ml 快捷记录按钮**：点一下直接记一杯，
  原通知替换为「已记 X ml · 今日累计 Y ml」的静默轻提示，3 秒自动消失
- 免打扰时段可自定义起止时间，**支持跨午夜**（如 22:00 – 次日 08:00）
- 用 `setExactAndAllowWhileIdle` 调度提醒，能穿过 Doze 投递。
  **不**用 `setAlarmClock`：它挡不住国产 ROM 自己的省电策略，却会让状态栏常驻一个闹钟图标
- **不**靠常驻前台服务保活 —— 进程活着反而会被国产 ROM 冻结，冻结后投递被丢弃
- 开机自启，重启后自动恢复提醒；被系统强制停止或覆盖安装后，重新打开应用会按**原定时刻**补排闹钟（不会把提醒往后推）
- 未关闭电池优化时，提醒卡片会提示「可能不提醒」并给出关闭入口；
  **OPPO 系（OPPO / realme / 一加）则常驻显示后台运行引导** —— 实测依据见 [BACKGROUND.md](BACKGROUND.md)

## 桌面小部件

- 4×2 小部件：当日折算进度条 + 已记毫升数 + 与通知同款的三档快捷记录按钮，点空白处打开主界面
- 记录、删除、修改目标后实时刷新；跨午夜日期自动翻新；适配深色模式

## 更新

- 启动时检查版本清单，有新版本时弹窗提示，确认后下载 APK 并校验 SHA-256 再安装
- 自动检查最多每 12 小时一次；首页底部的「关于」里可以手动检查
  （手动检查忽略节流，并区分「已是最新」与「没查到」）
- 更新链路的完整原理（为什么读 Pages 清单、为什么不读 Releases API、字段契约）见 [RELEASE.md](RELEASE.md)

## 界面与主题

- Material 3 + 固定品牌蓝配色，完整适配深色模式（含深色冷启动，无白屏闪烁）
- 自适应启动器图标（Android 8+，桌面与系统闪屏显示蓝底白水滴，支持单色主题图标）
- 手机 / 平板 / DeX 均适配：内容列最大 480dp 居中，矮视口（小屏）自动收紧主视觉

## 使用说明

**首次启动**

- 会先进入三步引导（欢迎 → 资料与目标 → 提醒），按你的资料算出推荐每日目标；
  可随时跳过，之后可从「关于」重新运行
- Android 13+ 会弹出通知权限申请，允许后提醒才能显示
- Android 12+ 需在系统设置中授予「闹钟和提醒」权限，否则提醒不准时
- 部分国产 ROM 需手动允许自启动与后台运行，否则提醒会被杀掉
- **OPPO 系（OPPO / realme / 一加）必做**：设置 → 电池 → **应用耗电管理** → 本应用 →
  允许**完全后台行为**；以及设置 → 应用 → **自启动** → 允许。技术细节见 [BACKGROUND.md](BACKGROUND.md)

**日常使用**

- **记录**：首页点饮品卡片记一杯，或通过「自定义」输入任意毫升数，按水合系数折算入当日总量；
  也可以直接点提醒通知或小部件上的 +200/350/500 按钮
- **目标**：点首页的目标数字修改每日目标（1000 – 5000 ml，步长 100）
- **提醒**：首页进入「设置提醒」，选 1 / 2 / 3 小时间隔；可开启夜间免打扰并设起止时间（支持跨午夜）
- **历史**：从首页进入历史页，查看最近 7 天汇总、月度达标与月历；左滑或长按删除单条，或一键清空当日记录
- **小部件**：在桌面添加「喝水提醒」4×2 小部件，看当日进度、点按钮直接记一杯
- **导出**：历史页右上角的下载图标，可把全部记录导出为 CSV 备份（自行选择保存位置）
- **更新**：启动时自动检查，有新版本时在弹窗里点「立即更新」即可（自动检查最多每 12 小时一次）

## 验证边界

纯逻辑有 JUnit4 单元测试（`./gradlew testDebugUnitTest`，见 [DEVELOPMENT.md](DEVELOPMENT.md)），
**但提醒投递、下载 → 校验 → 安装、小部件等设备行为只能装到设备上手动验证**。
检查 `shared_prefs/update_prefs.xml` 里出现 `last_check_at` 只能证明请求到了 Manifest，
不证明版本比较与摘要校验逻辑对。
