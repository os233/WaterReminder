安装步骤

  1. 下载上面的 APK 文件
  2. 在文件管理器里点击它；系统会提示「不允许安装未知来源应用」
  3. 按提示为当前使用的浏览器或文件管理器打开「安装未知应用」权限，然后返回继续安装
  4. 安装完成后首次启动，允许通知权限（Android 13+）与「闹钟和提醒」权限（Android 12+），提醒才会准时

关于签名

所有正式版本都由同一份发布密钥签名。签名一致才能覆盖安装；如果你装的是别人改过的包，会因为签名不同而装不上 —— 这是 Android 的保护机制，不是故障。

旧版本

需要特定旧版本，或想核对每个版本的校验值，请到 GitHub Releases 查看全部发布记录。
